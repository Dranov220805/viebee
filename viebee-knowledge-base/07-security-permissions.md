# 07 — Security, Permissions & Privacy 🛡️

## 1. Role-Based Access Control (RBAC)

VieBee establishes three distinct security roles:

| Role | Permissions & Access Scope |
|---|---|
| **`TRAVELER`** | Search map, browse workshops, create RSVPs, chat with host via AI copilot, submit reviews. |
| **`HOST`** | Manage personal workshops, view incoming guest RSVPs, accept/decline bookings, track payouts (88%). |
| **`ADMIN`** | Full platform oversight, host ID verification, on-site space QC inspection, workshop moderation. |

---

## 2. Host Residential Privacy & Trust

Because workshops take place in private family homes:
- Exact floor/door numbers are withheld until an RSVP is confirmed.
- Only approximate alley coordinates are broadcast on the public GIS Cultural Map.
- All guest profiles require email or phone validation before an RSVP can be completed.
